# UI 设计 - 内容聚合器

## 设计目标

为"内容聚合器"功能提供与现有帖子展示统一的卡片式界面，区分聚合内容和用户原创内容，让来源出处清晰可见。

## 设计原则

- 对齐现有 UI 设计规范（卡片圆角、间距体系、字体层级、色彩方案）
- 聚合内容卡片与用户帖子卡片视觉统一，增加来源标识
- 来源出处清晰可辨，用户一眼知道内容来自哪个平台
- 管理后台保持简洁，单页面完成所有操作

## 关键组件

### 内容卡片（聚合版）
- 卡片容器：`rounded-xl border border-gray-200 bg-white p-5 shadow-sm transition hover:-translate-y-0.5 hover:shadow-md`
- 平台图标 + 类型标签：`inline-flex items-center gap-1 rounded bg-gray-100 px-2 py-0.5 text-xs text-gray-500`
- 标题：`text-base font-semibold text-gray-900 hover:text-primary-600 transition-colors`
- AI 摘要：`mt-1.5 text-sm text-gray-500 line-clamp-2`
- 元数据行：`mt-2 flex items-center gap-3 text-xs text-gray-400`
- 标签：`rounded-full bg-gray-100 px-2 py-0.5 text-[11px] text-gray-500`
- 来源出处链接：`text-gray-300 hover:text-gray-500 transition-colors`

### 板块标题
- `text-lg font-semibold text-gray-900`
- 右侧计数：`text-xs text-gray-400`

### 空状态
- 容器：`rounded-lg border-2 border-dashed border-gray-200 py-16 text-center`
- 图标：`text-4xl`
- 文案：`text-sm text-gray-400`

### 管理后台按钮
- 发布：`rounded bg-green-500 px-3 py-1 text-xs font-medium text-white hover:bg-green-600`
- 丢弃：`rounded bg-gray-200 px-3 py-1 text-xs font-medium text-gray-600 hover:bg-gray-300`
- 添加：`rounded-lg bg-gray-900 px-4 py-2 text-sm font-medium text-white hover:bg-gray-800`

## 响应式建议

- Mobile First：基准 375px
- 小屏：卡片全宽，`p-4`，标签最多显示 2 个
- md(768px)：卡片横向留白增加，首页 `max-w-4xl`
- lg(1024px)：管理后台左右分栏，采集+概览并排

## 状态设计

### 加载状态
- 板块内容加载：卡片骨架 `animate-pulse`，灰色块占位

### 空状态
- 板块无内容：`📭 {板块名} 板块还没有内容` + `采集到的内容会自动出现在这里`
- 无关注源：`📡 暂无关注源` + 添加种子博主入口
- 待审核为空：`暂无待审核内容`

### 错误状态
- 采集失败：静默跳过，记录到事件流（不打断用户浏览）
- 评测失败：内容进入待审核队列，人工处理

## 设计交付说明

1. 设计师输出 `docs/ui-内容聚合器.md`（本文档）
2. 聚合内容卡片复用现有帖子卡片样式，增加来源标识行
3. 管理后台为独立页面，仅管理员访问
4. 开发者可直接复用 Tailwind 类名示例
