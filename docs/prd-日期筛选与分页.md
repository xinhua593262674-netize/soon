# PRD - 内容列表增强：日期筛选与分页

## 背景与目标

当前假装社区的内容列表存在两个问题：

| 问题 | 现状 | 影响 |
|------|------|------|
| **无日期筛选** | 所有已发布内容一视同仁展示 | 用户无法只看"最近一周"的新内容；老内容混杂，信息密度下降 |
| **无分页** | 首页每个板块硬编码 `take: 20` | 超过 20 条的老内容永远不可见；内容越多，信息丢失越严重 |

随着内容持续采集累积（预计日均 10-30 条），这两个问题会越来越突出。

**目标：**
- 让用户能按时间范围筛选内容，快速定位最近一周/一月的热点
- 提供分页浏览能力，让所有历史内容都可回溯
- 日期筛选 + 场景筛选 + 分页三者可自由组合，不互斥

## 目标用户

- **日常浏览者（管理员本人）**：想快速扫一眼"最近一周 AI 圈发生了什么"
- **深度检索者（管理员本人）**：想回溯几个月前采集的某条内容

## 用户故事

- 作为浏览者，我希望在首页/板块页快速切换时间范围（今天/7天/30天/全部），以便只看我关心的时间段内的内容。
- 作为浏览者，我希望内容列表底部有分页器，以便逐页浏览历史内容而非只能看最新 20 条。
- 作为浏览者，我希望日期筛选和场景筛选能同时生效，以便精确命中"最近一周的 AI Coding 内容"。
- 作为浏览者，我希望 URL 能反映当前的筛选和分页状态，以便刷新页面或分享链接时筛选条件不丢失。

## 功能详述

### 1. 日期筛选（P0）

#### 1.1 快捷时间段

提供预设的时间范围选项，一键切换：

| 选项 | 含义 | 默认 |
|------|------|------|
| 全部 | 不限时间 | ✅ 默认 |
| 今天 | `publishedAt >= 今日 00:00` | |
| 最近 7 天 | `publishedAt >= 7 天前` | |
| 最近 30 天 | `publishedAt >= 30 天前` | |
| 最近 3 个月 | `publishedAt >= 90 天前` | |

#### 1.2 自定义日期范围（P1）

- 提供起止日期选择器
- 选择自定义范围后，快捷选项自动切换为"自定义"
- 起止日期均可选，不强制成对填写（允许只看"某天之后"）

#### 1.3 生效范围

日期筛选在以下页面均可用：
- **首页**：对每个板块下的内容列表生效，统一筛选
- **板块页**：对该板块内容生效
- **场景详情页**：对该场景下的内容生效

#### 1.4 URL 同步

日期筛选状态写入 URL searchParams，格式：

```
/?period=7d              # 最近7天
/?period=30d&page=2      # 最近30天 + 第2页
/?from=2026-05-01&to=2026-05-31  # 自定义范围（P1）
```

| 参数 | 值 | 说明 |
|------|---|------|
| `period` | `all` / `today` / `7d` / `30d` / `90d` / `custom` | 快捷时间段 |
| `from` | `YYYY-MM-DD` | 自定义起始日期（仅 custom） |
| `to` | `YYYY-MM-DD` | 自定义结束日期（仅 custom） |

### 2. 分页（P0）

#### 2.1 分页方式

采用**传统页码分页**（非无限滚动/加载更多），理由：
- 内容聚合器偏工具属性，用户可能想跳到特定页
- 支持 URL 直链，分享/书签友好
- 实现简单，不需要额外的滚动状态管理

#### 2.2 分页器规格

```
          ← 上一页   [1] [2] [3] ... [12]   下一页 →
                            ↑
                         当前页
```

| 属性 | 值 |
|------|---|
| 每页条数 | **20 条**（与现状一致） |
| 当前页指示 | 实心深色数字 |
| 可点击页码 | 灰色数字，hover 变色 |
| 省略号 | 当总页数 > 7 时，中间用 `...` 折叠 |
| 首尾页 | 始终可见（第 1 页和最后一页） |
| 当前页附近 | 当前页 ± 2 页始终可见 |
| 上一页/下一页 | 首尾页时置灰不可点击 |
| 总条数提示 | 分页器上方显示 "共 X 条内容" |

#### 2.3 URL 同步

```
/?page=2                  # 第2页
/?period=7d&page=3        # 最近7天 + 第3页
/?scenario=ai-coding&page=1&period=30d  # 场景 + 日期 + 分页
```

| 参数 | 值 | 默认 |
|------|---|------|
| `page` | 正整数 | `1` |

#### 2.4 边界情况

- 第 1 页：不显示"上一页"
- 最后一页：不显示"下一页"
- 筛选后无结果：显示空状态，不显示分页器
- 只有 1 页：不显示分页器
- 输入非法页码（如 `page=-1` 或 `page=abc`）：回退到第 1 页

### 3. 组合筛选

日期筛选 + 场景筛选 + 分页三者可自由组合，不可互斥。

#### 3.1 组合 URL 示例

```
# 场景「AI Coding」+ 最近30天 + 第2页
/scenarios/ai-coding?period=30d&page=2

# 板块「AI 教程」+ 全部时间 + 第1页
/boards/ai-tutorial?period=all&page=1

# 首页 + 最近7天
/?period=7d
```

#### 3.2 组合行为

- 切换日期 → 页码重置为第 1 页（因为数据总量变了）
- 切换场景 → 页码重置为第 1 页
- 切换页码 → 其他筛选条件不变
- 任一筛选条件变更，滚动到列表顶部

### 4. 首页特殊处理

首页按板块分组展示，日期筛选和分页策略：

- **日期筛选**：统一作用于所有板块（一个日期选择器，全局生效）
- **分页**：每个板块独立分页？还是首页整体分页？

**决策：首页不做分页，仅做日期筛选。**

| 理由 | 说明 |
|------|------|
| 首页定位 | 首页是"概览/发现"入口，不是深度浏览页 |
| 每板块 20 条 | 每个板块取最新 20 条，对首页足够 |
| 深入浏览 | 用户进入板块页/场景页后再做分页 |
| 复杂度 | 首页多板块分页会导致 URL 参数爆炸（`board_b_page=2`） |

首页日期筛选通过后，各板块展示该时间范围内的最新 20 条。

## 交互流程

### 浏览流程
```
首页 / 板块页 / 场景页
 │
 ├─ 顶部筛选栏: [全部 ▼] [全部时间 ▼] [场景筛选 chip]
 │   │
 │   ├─ 点击时间快捷选项 → URL 更新 + 页面刷新（或客户端即时筛选）
 │   └─ 切换时间 → 页码重置为 1
 │
 ├─ 内容列表（20条/页）
 │
 └─ 底部分页器: ← 上一页 [1] [2] [3] ... [8] 下一页 →
     │
     └─ 点击页码 → URL 更新 + 滚动到列表顶部
```

### URL 状态流转示意
```
进入首页
 → /?period=all                         (默认：全部时间)

点击「最近7天」
 → /?period=7d                          (日期变化 → page 重置为 1)

点击「第3页」
 → /?period=7d&page=3                   (叠加分页)

点击「AI Coding」场景 chip
 → /?period=7d&scenario=ai-coding&page=1  (场景变化 → page 重置为 1)
```

## 验收标准

### 日期筛选
- [ ] 首页/板块页/场景页顶部有日期快捷筛选（全部/今天/7天/30天/3个月）
- [ ] 切换时间段后，内容列表仅展示该时间范围内的内容
- [ ] 默认选中"全部"
- [ ] 日期切换后，分页自动回到第 1 页
- [ ] 日期筛选状态反映在 URL 上，刷新页面不丢失

### 分页
- [ ] 板块页和场景页底部展示分页器（总页数 > 1 时）
- [ ] 每页 20 条内容
- [ ] 分页器显示上一页/下一页/页码/省略号
- [ ] 点击页码正确跳转，URL 同步更新
- [ ] 第 1 页不显示"上一页"，最后页不显示"下一页"
- [ ] 只有 1 页时不显示分页器
- [ ] 筛选后无结果时显示空状态，隐藏分页器

### 组合筛选
- [ ] 日期筛选 + 场景筛选可同时生效
- [ ] 日期筛选 + 分页可同时生效
- [ ] 三者组合可同时生效
- [ ] 任一筛选变化，页码重置为 1

### 首页
- [ ] 首页日期筛选全局生效
- [ ] 首页不做分页（保持每板块最新 20 条）

## 优先级

| 优先级 | 功能 |
|--------|------|
| **P0** | 日期快捷筛选（首页/板块页/场景页）、分页器（板块页/场景页）、URL 同步 |
| **P1** | 自定义日期范围选择器 |
| **P2** | 首页板块折叠/展开、每页条数可配置（20/50/100） |

## 数据模型影响

**无新增表**。仅影响查询层：

- Content 查询增加 `where.publishedAt` 日期范围条件
- Content 查询增加 `skip` / `take` 分页参数
- 新增 `count` 查询获取总条数（计算总页数）

## 非功能性要求

- 分页查询响应时间 < 500ms（含 count）
- 日期筛选 + count 查询需有数据库索引支持（`publishedAt` 已有索引 ✅）
- URL 参数设计需向后兼容——不加参数时行为与当前一致
