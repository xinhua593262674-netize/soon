# 假装社区 产品需求文档

## 产品概述

假装社区是一款面向轻量社区用户的 Web 应用，围绕 AI 和技术话题打造简洁的发帖、讨论和发现体验。产品核心目标是降低社区参与门槛，让用户可以快速发布内容、浏览主题、互动交流。

## 背景与目标

当前项目已经搭建起一个基础社区首页、主题板块和内容分类体系。下一步目标是将这个项目发展成一个可用的轻量社区产品，满足用户的内容发布、阅读和互动需求。

目标：
- 让用户能快速发帖并被其他人发现
- 让社区互动变得顺畅且自然
- 保持界面和体验的简洁，适配移动端使用场景
- 通过话题分类让用户快速进入兴趣内容流

## 目标用户

1. AI / 技术资讯爱好者：想快速获取行业动态、产品信息和观点
2. 轻量内容创作者：希望用简洁方式发表想法、分享经验、发布教程
3. 社区互动用户：追求低门槛讨论、评论和交流，不需要复杂功能

## 用户故事

- 作为访客，我希望看到一个清晰的首页入口，以便快速了解社区定位和入口活动。
- 作为注册用户，我希望能直接发帖并选择话题板块，以便让内容更容易被感兴趣的人看到。
- 作为用户，我希望在帖子下留言讨论，以便与其他社区成员交流观点。
- 作为用户，我希望能给帖子点赞，以便表达对内容的认同。
- 作为用户，我希望看到不同话题板块的内容分类，以便按兴趣快速发现新帖子。
- 作为用户，我希望能够查看自己的个人主页，以便看到自己发布过的帖子和互动记录。
- 作为用户，我希望登录后能访问更多互动功能（发帖、评论、点赞），以便参与社区。
- 作为管理员/产品方，我希望通过埋点了解哪些话题最受欢迎，以便优化内容策略。

## 功能详述

### 1. 用户注册与登录（P0）
- 支持手机号/邮箱/账号注册与登录（当前可用最基础认证实现）
- 登录用户可以发帖、评论、点赞、访问个人主页
- 未登录用户可浏览首页、话题、帖子列表，但无法参与互动

### 2. 帖子发布与展示（P0）
- 发帖支持标题、正文、标签、选择话题板块
- 帖子卡片展示标题、摘要、标签、作者、发布时间和互动统计
- 首页/板块页显示帖子列表，支持快速浏览
- 帖子详情页展示完整内容和评论区

### 3. 评论与互动（P0）
- 登录用户可以对帖子发表评论
- 评论可按时间顺序展示，显示评论作者和时间
- 支持帖子的点赞功能

### 4. 话题板块与标签分类（P0）
- 基于 `lib/topics.ts` 中定义的板块体系，提供主题导航
- 用户在发帖时可选择目标板块
- 首页展示板块入口卡片，引导用户按兴趣进入

### 5. 个人主页（P1）
- 展示用户昵称、头像、简介
- 列出该用户发布的帖子
- 显示用户互动记录概览（点赞数、评论数）

### 6. 内容发现与探索（P1）
- 提供“探索”入口，展示热门话题和最新帖子
- 支持按板块筛选帖子
- 可在未来迭代中补充关键词推荐与标签筛选

### 7. 移动优先体验（P1）
- 页面布局应适配窄屏设备
- 核心交互按钮保持易点按
- 文字与卡片间距适中，避免视觉拥挤

### 8. 推荐/自动标签（P2，可后续）
- 根据标题和正文内容推荐标签
- 基于关键词自动归类到 AI 资讯、AI 教程等板块

## 交互流程

### 访客流程
1. 进入首页，了解社区定位
2. 点击“开始探索”进入板块或帖子列表
3. 浏览帖子详情
4. 点击登录入口进入注册/登录页

### 注册用户流程
1. 登录后进入个人主页或首页
2. 点击“发帖子”进入发布界面
3. 输入标题、正文、选择板块、添加标签
4. 发布后跳转到帖子详情页
5. 在帖子详情页查看评论、点赞、参与讨论

### 互动流程
1. 在帖子列表中选择一篇内容
2. 阅读帖子全文
3. 滚动至评论区查看已有讨论
4. 输入评论并提交
5. 点击“点赞”表达认同

## 验收标准

- [ ] 首页有明显“开始探索”与“了解更多”入口
- [ ] 帖子列表页能展示标题、摘要、作者、发布时间、点赞数
- [ ] 登录用户能成功发帖，并在帖子详情页看到已发布内容
- [ ] 登录用户能在帖子详情页发表评论
- [ ] 登录用户能对帖子执行点赞操作
- [ ] 访客能在不登录情况下浏览板块和帖子内容
- [ ] 板块导航与主题标签能够引导用户按兴趣发现内容
- [ ] 个人主页显示用户发布的帖子列表

## 优先级

- P0
  - 用户注册与登录
  - 帖子发布与展示
  - 评论与点赞互动
  - 话题板块与标签分类
- P1
  - 个人主页
  - 内容发现与探索入口
  - 移动优先体验优化
- P2
  - 自动标签/关键词推荐
  - 个性化推荐与高级筛选

## 数据埋点建议

- `page_view.home`：首页浏览
- `page_view.board`：板块页浏览
- `page_view.post`：帖子详情页浏览
- `action.post_create`：发布帖子
- `action.comment_create`：发表评论
- `action.post_like`：点赞帖子
- `action.login_success`：登录成功
- `action.signup_success`：注册成功
- `action.tag_click`：点击标签/板块

## 约束与非功能性要求

- 设计保持轻量，避免复杂社交功能
- 强调简单、清晰、移动优先
- 不包含实时聊天、私信、充值/付费、内容审核机制
- 后端实现应兼顾可维护性和可扩展性，避免一次性堆砌功能
