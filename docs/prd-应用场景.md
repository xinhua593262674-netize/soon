# PRD - 应用场景维度

## 背景与目标

当前假装社区的内容组织依赖两套体系：

| 维度 | 说明 | 示例 |
|------|------|------|
| **板块 (Board)** | 内容所属领域 | AI 资讯、AI 教程 |
| **标签 (Tag)** | 关键词匹配自动生成 | `claude-code`、`nextjs`、`cursor` |

缺失一个关键维度：**应用场景**。

用户在浏览内容时，最常见的心理模型不是「我想看 AI 教程」，而是「我想知道 AI 能帮我做什么」。例如：

- 「我想用 AI 写代码」→ 需要找到所有 AI Coding 相关内容
- 「我想用 AI 做 PPT」→ 需要找到所有 AI PPT 工具/教程
- 「我想用 AI 剪视频」→ 需要找到所有 AI 视频制作内容

**目标：**
- 新增「应用场景」作为独立的内容组织维度，与板块正交
- 让用户能按「我想干什么」来发现内容
- 降低内容发现门槛，提升浏览体验

## 目标用户

- **社区管理员（本人）**：发布/采集内容时可标注应用场景
- **访客浏览者**：通过场景入口快速定位自己关心的内容

## 用户故事

- 作为浏览者，我希望在首页看到按应用场景组织的入口，以便直接找到「AI Coding」「AI 做 PPT」等我关心的内容。
- 作为浏览者，我希望在内容卡片上看到该内容所属的应用场景，以便快速判断内容是否与我的需求相关。
- 作为浏览者，我希望能按场景筛选内容，以便只看某个场景下的所有内容。
- 作为管理员，我希望能为每条内容标注 1-N 个应用场景，以便内容能在多个场景入口下被找到。
- 作为管理员，我希望 AI 能根据内容标题和摘要自动推荐应用场景，以便减少手动标注工作量。

## 功能详述

### 1. 应用场景定义与管理（P0）

- **场景是全局的**，不隶属于某个板块。同一场景可跨越多个板块。
- 预设场景分类体系（可扩展）：

| 场景 ID | 场景名称 | 说明 |
|---------|----------|------|
| `ai-coding` | 🤖 AI Coding | AI 辅助编程、代码生成、IDE 插件 |
| `ai-ppt` | 📊 AI 做 PPT | AI 生成演示文稿、幻灯片工具 |
| `ai-video` | 🎬 AI 做视频 | AI 视频生成、剪辑、特效 |
| `ai-writing` | ✍️ AI 写作 | AI 文案、小说、公文、翻译 |
| `ai-drawing` | 🎨 AI 绘画 | AI 图像生成、风格迁移、修图 |
| `ai-data` | 📈 AI 数据分析 | AI 数据处理、可视化、报表 |
| `ai-automation` | ⚡ AI 自动化 | AI Agent、工作流、RPA |
| `ai-voice` | 🎙️ AI 语音 | TTS、语音克隆、音乐生成 |
| `ai-search` | 🔍 AI 搜索 | 智能搜索、知识库、RAG |
| `ai-design` | 🧑‍🎨 AI 设计 | UI 设计、Logo、海报生成 |

- 管理员可在后台新增/编辑/禁用场景
- 每个场景有：名称、slug、icon（emoji）、描述、排序权重

### 2. 内容与场景关联（P0）

- 一条内容可关联 **1~3 个应用场景**（多对多）
- 关联方式：
  - **AI 自动推荐**（默认）：采集评测时，由 AI 根据标题+摘要+标签推荐场景
  - **手动指定**：管理员在后台可为内容勾选/修改场景
- 若 AI 推荐置信度低于阈值（如 < 60%），标记为「待人工确认」

### 3. 场景入口与展示（P0）

#### 3.1 首页场景导航
- 在现有板块列表上方，新增「按场景浏览」横滑卡片区
- 每个场景一个图标卡片：emoji + 名称 + 内容计数
- 点击进入场景详情页（该场景下的所有内容，按板块分组或按时间排序）

#### 3.2 内容卡片上的场景标签
- 在内容卡片元数据行中，展示该内容关联的场景标签
- 样式区别于普通标签（例如使用彩色背景或添加 emoji 前缀）
- 点击场景标签 → 跳转到该场景详情页

#### 3.3 场景筛选
- 板块页顶部增加场景筛选器（横向可滚动 chip 列表）
- 选中某场景后，内容列表仅显示关联该场景的内容
- 支持与板块组合筛选（如「AI 教程」板块 ×「AI Coding」场景）

### 4. 场景统计与排序（P1）

- 每个场景的内容计数、最近更新时间
- 支持按「最新」「最热」排序
- 场景入口可按内容数量降序排列（热门场景优先展示）

## 交互流程

### 场景浏览流程
```
首页
 ├─ 看到「按场景浏览」区域（10 个场景卡片横向滚动）
 ├─ 点击「AI Coding」场景卡片
 │   ├─ 进入 /scenarios/ai-coding
 │   ├─ 展示该场景下所有内容（按时间倒序）
 │   ├─ 顶部可切换板块筛选
 │   └─ 每个内容卡片上仍显示其场景标签
 └─ 也可在板块页中使用场景筛选器
```

### 场景标注流程（管理员）
```
管理后台 → 内容列表
 ├─ 每条内容旁显示已关联的场景标签
 ├─ 点击编辑 → 勾选/取消场景（多选，最多 3 个）
 └─ AI 自动推荐场景，低置信度内容高亮提示
```

### 采集自动标注流程
```
新内容采集入库
 → AI 评测通过（≥3.5）
 → 同时调用场景识别 AI：分析标题+摘要
 → 返回推荐场景列表 + 置信度分数
 → 置信度 ≥60%：自动关联
 → 置信度 <60%：标记待人工确认
```

## 验收标准

- [ ] 首页展示「按场景浏览」入口区域，至少展示 8 个预设场景
- [ ] 点击场景卡片可进入场景详情页，展示该场景下所有已发布内容
- [ ] 内容卡片上显示场景标签，样式区别于普通标签
- [ ] 板块页支持按场景筛选内容
- [ ] 管理后台可为每条内容手动标注/修改场景（多选，上限 3 个）
- [ ] 新采集内容入库后，AI 自动推荐场景并关联（置信度 ≥60% 自动生效）
- [ ] 低置信度场景推荐在后台高亮提示，等待人工确认
- [ ] 场景可正常新增、编辑、禁用

## 优先级

| 优先级 | 功能 |
|--------|------|
| **P0** | 场景定义与管理、内容-场景关联、首页场景入口、内容卡片场景标签、场景详情页 |
| **P1** | 板块页场景筛选器、AI 自动场景推荐、场景统计排序 |
| **P2** | 个性化场景推荐（基于浏览历史）、场景趋势/热度排行 |

## 数据模型影响

新增 `Scenario` 模型 + `ContentScenario` 关联表：

```
Scenario
  id, name, slug(unique), icon, description, order, isActive, createdAt

ContentScenario (多对多)
  contentId, scenarioId, confidence (AI 置信度), isManual (是否人工指定)
```

## 非功能性要求

- 场景列表加载 < 200ms
- 场景筛选不影响板块原有加载性能
- 数据模型支持未来扩展到 20+ 场景
- 场景入口在移动端需支持横向滑动
