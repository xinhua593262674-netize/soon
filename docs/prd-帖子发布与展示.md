# PRD - 帖子发布与展示

**角色**：产品经理（product）

## 背景与目标

“假装社区”核心价值是让用户快速发布和发现 AI / 技术内容。帖子发布与展示是社区最关键的功能，决定用户是否愿意留下来发帖、浏览和参与讨论。

目标：
- 提供简洁易用的发帖入口
- 让帖子内容在首页、板块页和详情页中清晰展现
- 支持评论与点赞，形成简单互动闭环

## 目标用户

- AI / 技术资讯爱好者
- 轻量内容创作者
- 喜欢低门槛讨论的社区用户

## 用户故事

- 作为注册用户，我希望快速写一条帖子，以便分享我的观点和经验。
- 作为用户，我希望选择合适的板块或标签，以便让感兴趣的人看到我的帖子。
- 作为用户，我希望在首页/板块页看到帖子摘要，以便快速决定是否阅读。
- 作为用户，我希望进入帖子详情页查看完整内容和评论，以便参与讨论。
- 作为用户，我希望能点赞帖子，以便表达认同。
- 作为用户，我希望能对帖子发表评论，以便与作者和社区互动。
- 作为访客，我希望能浏览帖子列表和详情，以便了解社区内容并决定是否登录。

## 功能详述

### 帖子发布
- 登录后可进入“发帖”页面/弹窗。
- 表单字段：帖子标题、正文、板块选择、标签输入。
- 标题限制 200 字符，正文支持多行文本。
- 发布后跳转到帖子详情页。

### 帖子列表
- 首页和板块页展示帖子卡片。
- 卡片信息：标题、摘要、作者昵称、发布时长、板块、点赞数、评论数。
- 按最新发布排序，后续可补充热门排序。

### 帖子详情
- 展示完整标题、正文、作者、发布时间、板块、标签。
- 显示互动统计：点赞数、评论数。
- 提供评论输入区和评论列表。

### 评论与点赞
- 登录用户可发表评论。
- 评论显示作者、时间和评论内容。
- 登录用户可为帖子点赞/取消点赞。
- 未登录用户点击评论或点赞时，提示登录。

### 话题分类
- 参考 `lib/topics.ts` 中的板块定义。
- 发布时允许选择一个主板块。
- 首页提供板块入口卡片，引导用户浏览分类内容。

## 交互流程

### 发帖流程
1. 用户点击“发帖”。
2. 填写标题和正文，选择板块，可添加标签。
3. 点击“发布”。
4. 系统保存帖子，跳转到帖子详情页。

### 浏览流程
1. 用户打开首页或板块页。
2. 浏览帖子卡片。
3. 点击帖子标题进入详情页。
4. 阅读完整内容，查看评论和互动按钮。

### 评论流程
1. 登录用户在帖子详情页输入评论。
2. 点击“发送”。
3. 评论添加到列表，页面滚动到最新评论。

### 点赞流程
1. 登录用户点击帖子详情页的点赞按钮。
2. 点赞数实时更新。
3. 再次点击可取消点赞。

## 验收标准

- [ ] 登录用户能成功发布帖子，并在详情页看到已发布内容。
- [ ] 未登录用户能浏览帖子列表和帖子详情。
- [ ] 登录用户能在帖子详情页发表评论。
- [ ] 登录用户能对帖子点赞/取消点赞。
- [ ] 帖子列表显示标题、摘要、作者、发布时间、板块、点赞数、评论数。
- [ ] 发帖时必须选择板块，且发布后帖子正确归类。
- [ ] 评论区显示评论作者和发布时间。

## 优先级

- P0：帖子发布、帖子列表、帖子详情、评论、点赞、板块分类
- P1：移动端适配、空状态提示、帖子标签展示
- P2：热门排序、推荐标签、帖子编辑/删除

## 数据埋点建议

- `action.post_create`：用户发布帖子
- `action.post_view`：帖子详情页浏览
- `action.post_like`：帖子点赞
- `action.comment_create`：发表评论
- `action.board_click`：点击板块入口
