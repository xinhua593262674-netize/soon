# PRD - 内容聚合器

## 背景与目标

当前"假装社区"的用户自行发帖内容门槛高、产量低。需要一套自动采集+评测+发布的内容管道，从优质源持续补充 AI 资讯和 AI 教程板块。

目标：
- 自动从 GitHub / YouTube / B站 采集 AI 领域优质内容
- AI 五维评测自动筛选（相关性/质量/时效/互动/完整度）
- 内容自动填充到板块，保持社区内容活跃
- 管理员可手动采集、审核、管理关注源

## 目标用户

- 唯一使用者：社区管理员本人（个人内容聚合器）
- 无需开放注册、无需多用户权限

## 用户故事

- 作为管理员，我希望系统自动从关注源采集 AI 资讯和教程，以便板块持续有新鲜内容。
- 作为管理员，我希望 AI 自动对采集内容进行多维评分，以便筛选高质量内容自动发布。
- 作为管理员，我希望查看待审核内容的评分详情，以便一键发布或丢弃。
- 作为管理员，我希望手动粘贴链接采集内容，以便补充自动采集未覆盖的优质内容。
- 作为管理员，我希望管理关注源（种子博主/UP主/仓库），以便控制内容来源。

## 功能详述

### 1. 自动内容采集（P0）
- 支持平台：GitHub、YouTube、B站（小红书/抖音预留）
- 定时触发：GitHub Actions 每天 3 次（北京时间 8:00/14:00/20:00）
- 采集范围：管理员配置的种子博主/UP主/仓库
- 采集内容：标题、原始链接、摘要、缩略图、发布时间、互动数据

### 2. AI 评测与自动发布（P0）
- 评测维度：相关性 30%、质量 25%、时效 20%、互动 15%、完整度 10%
- 自动决策：≥3.5 发布 / 2.5-3.5 待审核 / <2.5 丢弃
- 相关性为 0 直接丢弃（内容不匹配任何板块）
- 评测记录持久化，支持回溯

### 3. 内容展示（P0）
- 首页按板块展示已发布内容
- 卡片式布局（对齐 UI 设计规范）
- 展示：标题、AI摘要、来源出处（平台+博主+原文链接）、互动统计、标签

### 4. 管理后台（P0）
- 手动采集：粘贴链接 → 选择板块 → 自动评测 → 入库
- 审核队列：查看待审核内容 + 评分详情 → 一键发布/丢弃
- 关注源管理：添加/查看种子博主，标注平台和归属板块

### 5. 源平台评论展示（P1）
- 采集时抓取热评并展示在内容详情页
- 站内不支持直接评论（个人使用，无需互动）

### 6. 种子博主 AI 扩散（P2）
- 基于种子博主的内容相似度推荐新源
- 管理员审核后加入白名单

## 交互流程

### 自动采集流程
1. GitHub Actions 定时触发
2. 爬虫读取各板块关注源
3. 并发调用各平台 API 获取最新内容
4. 对每条内容运行五维评测
5. 自动发布/待审核/丢弃
6. 首页和板块页实时展示

### 手动采集流程
1. 管理员在后台粘贴链接
2. 系统提取内容+评测
3. 进入待审核（或达到阈值自动发布）
4. 管理员可在审核队列中发布/丢弃

### 浏览流程（与现有帖子浏览一致）
1. 打开首页 → 按板块查看内容卡片
2. 点击卡片 → 查看完整内容 + 来源出处 + 评论
3. 可跳转原文/原视频

## 验收标准

- [ ] GitHub/YouTube/B站 任一台可成功采集并按评测结果自动发布/待审核
- [ ] 评测引擎对相关性为 0 的内容自动拒绝
- [ ] 首页按板块展示已发布内容，含来源出处
- [ ] 管理后台可手动粘贴链接完成采集入库
- [ ] 管理后台可查看和操作待审核队列
- [ ] 管理后台可添加和查看关注源
- [ ] 内容卡片样式对齐 UI 设计规范

## 优先级

- P0：自动采集、AI 评测、内容展示、管理后台
- P1：源平台评论展示、评测详情可视化
- P2：种子博主 AI 扩散推荐、小红书/抖音支持

## 数据埋点建议

- `crawl.trigger`：采集触发（auto/manual）
- `crawl.item_collected`：单条内容采集成功
- `eval.auto_publish`：自动发布
- `eval.manual_review`：进入待审核
- `eval.auto_reject`：自动丢弃
- `admin.manual_collect`：手动采集
- `admin.review_action`：审核操作（发布/丢弃）
- `admin.source_add`：添加关注源
