# PRD - 来源切换、内容详情页、评论采集、种子博主扩展

## 背景与目标

当前假装社区已上线 50 条内容，但存在明显短板：

| 问题 | 现状 | 影响 |
|------|------|------|
| B站 0 条内容 | 8 个源 UID 全是假的 | 缺少中文 AI 视频内容 |
| YouTube 仅 3 个频道有效 | 16 个源只有 3 个有产出 | 英文视频覆盖不足 |
| 无平台切换 | 所有内容混在一起 | 用户无法只看"B站"或"YouTube" |
| 无内容详情页 | 点击标题跳原文 | 无法在站内查看完整内容 |
| 无评论 | Comment 模型存在但爬虫未采集 | 内容缺少社区感 |
| 种子源质量差 | 随手填的 UID/channelId | 大量无效源 |

**目标：**
- 建立种子博主质量筛选机制，替换掉无效源
- 内容卡片增加平台来源筛选（全部 / B站 / YouTube / GitHub）
- 新增内容详情页（完整展示 + 评论 + 来源出处）
- 爬虫增加评论采集

## 目标用户

- **管理员**（本人）：筛选高质量 AI 博主，查看评论了解内容反馈
- **浏览者**（本人）：按平台筛选内容，在站内查看完整信息

## 用户故事

- 作为浏览者，我希望按平台（B站/YouTube/GitHub）筛选内容，以便只看我关心的视频或仓库。
- 作为浏览者，我希望点击内容卡片后进入站内详情页，以便查看完整摘要、评论和元数据。
- 作为浏览者，我希望在详情页看到源平台的评论，以便了解其他观众/开发者的反馈。
- 作为管理员，我希望爬虫自动采集每条内容的评论，以便内容更有信息量。
- 作为管理员，我希望有一批真正优质的 AI 博主源，以便采集的内容质量高、覆盖广。

## 功能详述

### 1. 平台来源筛选（P0）

- 在所有内容列表顶部增加平台筛选 chip 行
- 选项：全部 / 📺 B站 / ▶️ YouTube / 📦 GitHub
- 与日期筛选、场景筛选、分页可组合使用
- URL 参数 `platform=bilibili|youtube|github`

### 2. 内容详情页（P0）

- 路由 `/contents/[id]`
- 页面内容：
  - 标题、平台来源标识（平台 icon + 博主名）
  - AI 摘要（完整展示，不截断）
  - 元数据（发布时间、观看数/星标数/互动数等）
  - 场景标签 + 关键词标签
  - 评论列表（来自源平台）
  - 原文链接按钮（跳转到 B站/YouTube/GitHub）
  - 「返回」和「下一篇」导航

### 3. 评论采集（P0）

- 爬虫在采集内容时，同步采集该内容的评论
- YouTube：通过 YouTube Data API v3 获取 `commentThreads`
- B站：通过 B站 API 获取评论
- GitHub：采集 Issue/Discussion 作为评论
- 每条评论：作者名、头像、正文、点赞数、平台、时间
- 已存在内容：跑一次回填脚本

### 4. 种子博主质量筛选（P0）

| 维度 | B站 | YouTube |

| 内容垂直度 | 主要做 AI/编程/工具教程 | 主要做 AI/ML/Dev工具 |
| 更新频率 | 近 30 天有更新 | 近 30 天有更新 |
| 内容语言 | 中文 | 英文/中文均可 |

## 交互流程

### 平台筛选流程
```
首页 / 板块页 / 场景页
 │
 ├─ 筛选行:  时间 [全部▼]  平台 [全部] [📺 B站] [▶️ YouTube] [📦 GitHub]  场景 [...]
 │   └─ 点击平台 chip → URL 更新，列表刷新
 │
 ├─ 内容卡片（增加平台 icon 标识）
 │
 └─ 点击卡片 → 进入内容详情页
```

### 内容详情浏览流程
```
内容卡片
 └─ 点击 → /contents/[id]
     ├─ 平台标识 + 标题 + 发布时间
     ├─ 完整摘要
     ├─ 元数据区（观看/星标/互动）
     ├─ 场景标签 + 关键词标签
     ├─ 📝 评论列表（按热度排序）
     └─ 🔗 查看原文（跳转到原始平台）
```

### 种子博主管理流程
```
管理后台 → 种子源管理
 ├─ 按平台筛选（B站/YouTube/GitHub）
 ├─ 每个源展示：名称 + 平台 + 粉丝数 + 内容数
 ├─ 失效标记：30 天无内容自动标记 ⚠️
 └─ 新增：粘贴 URL → 自动识别平台 → 添加
```

## 验收标准

### 平台筛选
- [ ] 首页/板块页/场景页顶部有平台筛选 chip（全部/B站/YouTube/GitHub）
- [ ] 选中平台后，列表仅显示该平台内容
- [ ] 平台筛选与日期/场景/分页可组合
- [ ] URL 参数反映筛选状态

### 内容详情页
- [ ] `/contents/[id]` 页面正常展示
- [ ] 展示完整摘要、元数据、标签、场景
- [ ] 展示源平台评论列表
- [ ] 有返回按钮和原文链接

### 评论采集
- [ ] GitHub Actions 跑采集时同步采集评论
- [ ] 新内容入库时评论一同入库
- [ ] 评论正确关联到内容

### 种子博主
- [ ] B站源替换为真实 UID，能正常采集到内容
- [ ] YouTube 源替换为真实 channelId，采集覆盖率 > 50%
- [ ] 管理后台展示源质量指标（内容数/最近采集时间）
